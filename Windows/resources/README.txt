XCX 4.3 — Compiler & Runtime (Windows)

XCX is a backend programming language with a built-in JIT-enabled runtime.

--------------------------------------------------

INSTALLATION
1. Run "xcx-setup.exe" and follow the installer wizard.
2. Open a new CMD or PowerShell window.
3. Verify the installation by running:
   xcx --version

--------------------------------------------------

USAGE
Run a script:
   xcx script.xcx

Start the interactive shell (REPL):
   xcx

--------------------------------------------------
